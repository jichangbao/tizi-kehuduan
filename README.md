## 安装后三步用起来

1. 买一个梯子订阅（不知道选哪家：[梯子推荐](https://tiziking.com/)，或本账号的 [tizi-tuijian](https://github.com/jichangbao/tizi-tuijian) 清单）。
2. 复制订阅链接，在客户端里导入（[订阅导入教程](https://tiziking.com/jiaocheng/daoru-dingyue/)）。
3. 选择节点，打开系统代理或 TUN 模式（[TUN 模式怎么开](https://tiziking.com/jiaocheng/tun-kaiqi/)）。

## 常见问题

**iPhone 在国区 App Store 搜不到小火箭？**
这些 App 只在外区上架，需要外区 Apple ID：[美区 Apple ID 注册教程](https://tiziking.com/jiaocheng/meiqu-apple-id-zhuce/)、[小火箭购买教程](https://tiziking.com/jiaocheng/xiaohuojian-goumai/)。

**订阅更新失败？**
见 [订阅更新失败怎么办](https://tiziking.com/jiaocheng/dingyue-gengxin-shibai/)。

**规则模式和全局模式选哪个？**
日常选规则模式，见 [规则模式设置](https://tiziking.com/jiaocheng/guize-moshi-shezhi/)。
